# 梦幻新诛仙工具箱

一个专为《梦幻新诛仙》游戏玩家打造的实用工具箱，提供各种游戏辅助计算和转换功能。

## 🎮 项目简介

这是一个基于现代 Web 技术构建的游戏工具集合，旨在为梦幻新诛仙玩家提供便捷的游戏数据处理工具。

## ⚒️ 当前功能

### 🗡️ 武器转换器

- **多等级支持**：支持 60 级、110 级武器
- **职业转换**：支持物理、法师、治疗、封印四大职业间的属性转换
- **属性计算**：精确计算物攻、法攻、治疗属性的转换值
- **表单校验**：确保输入数据的完整性和有效性
- **响应式设计**：完美适配 PC 端和移动端

### 核心特性

- ✅ 实时属性转换计算
- ✅ 输入数据校验
- ✅ 移动端友好界面
- ✅ 错误提示和用户引导

## 🚀 技术栈

- **前端框架**：React 19.1.1
- **开发语言**：TypeScript 5.8.3
- **构建工具**：Vite 7.1.2
- **样式框架**：Tailwind CSS 3.3.3
- **代码规范**：ESLint + TypeScript ESLint
- **包管理器**：pnpm

## 📦 安装与运行

```bash
# 克隆项目
git clone <repository-url>

# 进入项目目录
cd mz-tools

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览生产版本
pnpm preview
```

## 🔧 开发说明

### 项目结构

```
src/
├── components/          # React 组件
│   └── WeaponConverter.tsx
├── hooks/              # 自定义 Hooks
│   └── useWeaponConverter.ts
├── App.tsx             # 应用入口
└── main.tsx            # 项目启动文件
```

### 核心功能模块

- **useWeaponConverter**：武器转换核心逻辑
- **WeaponConverter**：武器转换器 UI 组件
- **属性转换算法**：基于比例的属性值转换
