# 产品资料来源

## 维护原则

- 优先使用《梦幻新诛仙》官网、官方公告和官方攻略。
- 产品中保留原文链接、发布日期和快照核验日期。
- 旧资料只用于说明基础定位，不推断后续新增流派或数值。
- 发现版本变化时，先更新来源记录，再调整产品文案和测试。
- 当前快照核验日期：2026-07-16。
